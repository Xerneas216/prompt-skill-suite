# building-prompt-packages baseline

## RED controls

Three reused-context controls were run before the controller and schema existed. They are useful comparisons but are not fresh-context acceptance tests.

1. Board-minutes summary: routed the general task sensibly and preserved conversation-only delivery, but invented noncanonical `package`, `contract`, `prompt`, and `evaluation` structures plus unapproved 100-percent recall and zero-drift gates.
2. Supplier research and approved email: preserved write approval and withheld tool-schema invention, but returned another noncanonical outline rather than a machine-validatable PromptPackage.
3. React dashboard diagnosis: routed software and tool behavior, kept diagnosis read-only, and marked evaluation `not_run`, but used custom top-level and conditional fields with no deterministic JSON-to-Markdown path.

Observed failures to repair: without a canonical interface, independently reasonable outputs drift structurally and can add unapproved evaluation policy.

Five independent fresh-context controls: `not_run` because this session has no remaining fresh agent slots. No dynamic-quality claim is made.

## Deterministic RED/GREEN

The first test run failed at import because the validator, renderer, and installer did not exist. After implementation and whole-branch review repairs, 42 deterministic tests pass for schema, JSON-Pointer protection of every explicit value, executable and schema-valid tool contracts, semantic references and dependency cycles, dynamic Markdown fences, rendering, provider-neutral fixtures, dry-run installation, manifest-driven staging, concurrent-target safety, atomic manifest failure cleanup, partial-copy cleanup, exact copied-file sets, and source-to-copy hashes.

## Behavioral GREEN result

With the controller and applicable sub-skills loaded, the repeated board-minutes case returned a ready general, single-turn, conversation-only package outline with exactly the nine canonical non-tool top-level fields. It routed the five required modules, preserved `gpt-5.6`, omitted `tool_policy`, used `not_run` for dynamic and baseline evaluation, introduced no persistent reasoning configuration, wrote no files, and added no numeric quality gate beyond the user's 300-character constraint. The RED structural drift and invented-threshold failures were not repeated.
